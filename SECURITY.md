# Security Policy

**Do not report security vulnerabilities as issues in this repository.** Issues here are public, and a public report puts Cloudflare users at risk before a fix can be shipped. If you have already opened one, close it and use one of the channels below instead.

## Reporting a vulnerability

Report vulnerabilities through **HackerOne**: https://hackerone.com/cloudflare

All Cloudflare products are in scope. Cloudflare's vulnerability disclosure policy is at https://www.cloudflare.com/disclosure/, and the canonical contact list is published at https://www.cloudflare.com/.well-known/security.txt — always prefer whatever that file says if it disagrees with this page.

## Reporting abuse

Abuse, phishing and malware reports go to Cloudflare's Trust & Safety team: https://www.cloudflare.com/abuse/

## Everything else

For non-security bugs in Cloudflare products, the dashboard or the REST API, [open an issue](https://github.com/cloudflare/cf-platform-issues/issues/new/choose) — see [README.md](./README.md). For anything specific to your account, contact [Cloudflare Support](https://dash.cloudflare.com/?to=/:account/support).
